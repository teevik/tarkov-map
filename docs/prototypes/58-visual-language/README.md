# Prototype — visual language for the new overlays (#58)

Throwaway. Three variants of the marker/area *visual language* for Boss Spawns,
Sniper Zones, Minefields, Transits, Switches and BTR Stops, drawn on the real map
with real upstream data.

Run: `nix develop -c cargo run --bin tarkov-map` on this branch.
Switch variants with the yellow bar at the bottom of the map or ← / →; `K` toggles
greedy label culling; the sidebar gains a "PROTOTYPE OVERLAYS" block with the six
new toggles drawn with the variant's glyph.

Screenshots: `TARKOV_MAP_PROTO_SHOTS=<dir> cargo run --bin tarkov-map` writes one
PNG per variant × scene and exits. Under Hyprland the window size is the WM's;
`shoot.sh` floats it at 1100×900 first (Hyprland 0.56 Lua API).

Data: `overlays.json` is generated by `gen.py` from `json.tarkov.dev/regular/maps`
+ `maps_en` (fetched 2026-08-18), folded per #33 (alt maps merged, bosses collapsed
per position, coordinates rounded to 2 dp).

| Variant | Markers | Areas | Labels |
|---|---|---|---|
| A — Solid shapes | opaque fill + dark stroke (black diamond boss, teal square transit, yellow dot switch, gold octagon BTR) | filled + solid stroke; 5 px square fallback | outlined white text (today's extract style) |
| B — Hue families + chips | danger = crimson (skull-dot boss), navigation = cyan (chevron transit, diamond switch, stop-sign BTR) | filled; sniper zones dashed magenta | dark pill chips with coloured edge |
| C — Icons on dark discs | near-black disc + coloured ring + vector icon (skull, chevrons, bolt, octagon) | outline-first, faint fill; minefields dashed; 5 px square fallback | outlined text tinted with the marker's colour |

Scenes: `lighthouse-fit` (+ `-nocull`), `lighthouse-zoom3`, `ground-zero-fit`
(+ `-nocull`), `ground-zero-zoom3`, `the-lab-fit`, `the-lab-zoom2`, `woods-fit`,
`streets-zoom2`, `interchange-fit`. Files: `shots/<A|B|C>-<scene>.png`.

Verdict: see the resolution comment on issue #58.
